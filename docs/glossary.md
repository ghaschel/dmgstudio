# Glossary

- **App bundle**: a directory ending in `.app` with `Contents/Info.plist`.
- **Canvas**: the background image dimensions used for Finder bounds and icon coordinates.
- **Finder layout**: icon-view settings persisted while the writable DMG is mounted.
- **UDRW**: writable disk-image format used during staging.
- **UDZO**: compressed read-only disk-image format published as final output.
- **Volume icon**: the mounted disk’s Finder icon, either custom or derived from the packaged app.
